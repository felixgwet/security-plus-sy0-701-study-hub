### Questions

**Q1.** A security analyst reviews logs and finds that an attacker gained access to the network seven months ago and has been slowly copying archived design documents to an external server ever since. The attacker has made no attempt to disrupt operations or encrypt data. Which of the following BEST describes this type of threat actor/activity?

A. Script kiddie conducting opportunistic scanning
B. An advanced persistent threat focused on data exfiltration
C. A hacktivist conducting a denial-of-service campaign
D. Organized crime conducting a ransomware attack

**Q2.** An attacker emails a victim claiming to have compromising photos and demands payment in Bitcoin or the photos will be published. Which motivation BEST describes this attack?

A. Financial gain
B. Service disruption
C. Blackmail
D. Data exfiltration

**Q3.** A company discovers an employee has been storing customer contracts in a personal Dropbox account to make working from home easier. No malice is suspected. Which of the following BEST describes this situation?

A. Insider threat
B. Shadow IT
C. Hacktivism
D. A false flag attack

**Q4.** During attribution analysis of a malware attack on a European bank, investigators find code that closely mimics a known Chinese state-sponsored group's tooling. Deeper analysis reveals subtle clues indicating the true source was a criminal group in another country attempting to redirect blame. Which of the following does this BEST describe?

A. Plausible deniability via proxy operation
B. A false flag attack
C. An evil twin campaign
D. A baiting attack

**Q5.** Which of the following BEST describes the difference between a threat vector and an attack surface?

A. A threat vector is a specific vulnerability; an attack surface is the tool used to exploit it
B. A threat vector is the pathway/means used to deliver an attack; the attack surface is the sum of all entry points and vulnerabilities that can be exploited
C. A threat vector applies to external actors only; an attack surface applies to insiders only
D. A threat vector is hardware-based; an attack surface is software-based

**Q6.** An attacker leaves malware-infected USB flash drives in the targeted company's parking lot and lobby. An employee finds one and plugs it into their workstation, installing the malware. Which technique is the attacker using?

A. Vishing
B. Baiting
C. Doxxing
D. Pharming

**Q7.** Which of the following is the PRIMARY purpose of deploying a honeypot on an enterprise network?

A. To block and prevent attacks against production systems
B. To gather information about attacker methods, motives, and TTPs
C. To patch vulnerabilities before attackers can exploit them
D. To increase the attack surface as a distraction

**Q8.** A group defaces several government websites with political slogans and leaks internal emails to protest a new surveillance law. The group has stated it wants no money and takes credit publicly for the attention. Which type of threat actor is this MOST likely?

A. Organized crime
B. Nation-state actor
C. Hacktivist
D. Unskilled attacker

**Q9.** An administrator places a fake user account named "svc-backup-99" in Active Directory that no legitimate user or service will ever use. Any authentication attempt against it triggers a high-priority alert. Which deception technology is being used?

A. Honeyfile
B. Honeytoken
C. Honeynet
D. Bogus DNS entry

**Q10.** Which nation-state actor is the well-known EXCEPTION to the rule that nation-state attacks are not financially motivated?

A. Russia — funding operations through election influence campaigns
B. China — stealing intellectual property for economic advantage
C. North Korea — conducting operations against banks and cryptocurrency exchanges to fund the regime
D. Iran — deploying destructive wiper malware

**Q11.** A cybersecurity researcher uses a tool downloaded from a forum to launch a DDoS against a gaming server, entering only the target's IP address and clicking a button. The researcher could not write or modify the tool and did it for notoriety among peers. Which of the following BEST describes this actor?

A. Hacktivist with high sophistication
B. Script kiddie / unskilled attacker
C. APT operator
D. Organized crime affiliate

**Q12.** The 2017 "Stegano" campaign hid malicious code inside the pixels of banner advertisements on popular websites, exploiting older browsers and silently redirecting victims to an exploit kit. Which threat vector does this represent?

A. Message-based
B. File-based
C. Image-based
D. Voice call-based

**Q13.** Which of the following BEST describes a false flag attack?

A. An attack launched from a compromised third-party system to gain resources
B. An attack orchestrated to appear as if it originated from a different source or group, to mislead investigators and misattribute the attack
C. An attack that plants false data in a database to trigger alarms
D. An attack that spoofs a legitimate Wi-Fi network to intercept traffic

**Q14.** A large retailer is hit with carefully crafted phishing emails and fake websites designed to steal employee credentials, followed by custom malware deployed to capture payment card data. The operation is run by a structured, well-funded group operating across multiple countries, motivated purely by profit. Which threat actor type is MOST likely responsible?

A. Hacktivists
B. Nation-state actors
C. Unskilled attackers
D. Organized crime

**Q15.** Which set of measures is MOST appropriate for mitigating insider threats?

A. Perimeter firewall rules and DMZ segmentation
B. Zero trust architecture, robust access controls, regular audits, and security awareness training
C. Anti-malware signatures updated daily and honeypots
D. Data loss prevention appliances only

**Q16.** An attacker sets up a rogue wireless access point named "Airport_Free_WiFi" that mimics the airport's legitimate network. Travelers who connect have their traffic intercepted and modified. Which technique is the attacker using?

A. Evil twin
B. BlueBorne
C. VLAN hopping
D. Baiting

**Q17.** Which of the following BEST describes tactics, techniques, and procedures (TTPs)?

A. The legal procedures for prosecuting cybercriminals across borders
B. The methods and patterns of activity or behavior associated with a particular threat actor or group, used to detect, mitigate, and counter threats
C. The documented steps an organization follows during incident response
D. The standard ports and protocols an attacker must use during an intrusion

**Q18.** A security team wants to observe how attackers move laterally between servers, routers, and switches over weeks-long campaigns in a controlled environment, logging both successful and failed attempts. Which deception technology BEST fits this requirement?

A. Honeynet
B. Honeyfile
C. Honeytoken
D. Port triggering

**Q19.** An attacker calls victims pretending to be from the tax authority, claiming immediate payment is owed and demanding credit card details over the phone, threatening arrest. Which threat vector and technique does this describe?

A. Message-based vector using phishing
B. Voice call vector using vishing
C. File-based vector using a Trojan
D. Image-based vector using steganography

**Q20.** Which statement about honeypots and honeynets is TRUE?

A. Honeynets prevent attackers from ever reaching production systems
B. A risk of honeypots/honeynets is that attackers can use them to learn how the organization's production systems are configured
C. Honeypots must be deployed inline between the firewall and production servers
D. Honeyfiles and honeynets are interchangeable terms

**Q21.** After being passed over for promotion, a senior system administrator copies a proprietary source-code repository to a personal drive on her last day and offers it to a competitor. Which motivation and attribute BEST describe this scenario?

A. Financial gain motivation; internal threat actor
B. Revenge motivation; internal threat actor
C. Espionage motivation; external threat actor
D. Disruption motivation; unskilled attacker

**Q22.** Which of the following actions will REDUCE an organization's attack surface? (Select TWO)

A. Disabling unused protocols on network segments
B. Allowing instant messaging for all departments to improve collaboration
C. Removing unnecessary software from servers
D. Issuing USB thumb drives to all employees
E. Deploying additional guest Wi-Fi networks without passwords

**Q23.** A security engineer plants a decoy spreadsheet named "Q4_Salaries.xlsx" containing fake data in a loosely protected share. The file contains hidden watermarks, and opening it triggers an alert; some versions even attempt to enumerate the attacker's network. Which deception technology is this?

A. Honeytoken
B. Honeyfile
C. Honeypot
D. Decoy directory

**Q24.** An organization's security posture is so restrictive and slow that a business unit buys its own cloud storage and installs unapproved browser plugins to stay productive. IT has no inventory or control of these systems. Which of the following BEST describes this condition and its primary risk?

A. Hacktivism; ideological attacks against the organization
B. Shadow IT; unapproved technology IT cannot secure, leading to potential data breaches, non-compliance, and disruption
C. An APT; long-term undetected compromise
D. Baiting; malware infection via removable media

**Q25.** Which motivation is MOST closely associated with ethical hackers and penetration testers?

A. Financial gain
B. Ethical reasons — improving security by finding and helping patch vulnerabilities before malicious actors exploit them
C. Disruption or chaos
D. Espionage

**Q26.** The Stuxnet worm is a classic example of which actor type and technique?

A. Organized crime using ransomware for financial gain
B. A nation-state actor using zero-day exploits and an infected USB drive to cross an air-gapped network and cause physical damage to critical infrastructure
C. Hacktivists using DDoS to protest nuclear policy
D. Script kiddies using pre-built DDoS tools

**Q27.** An attacker in a café exploits a vulnerability in the Bluetooth protocol stack of nearby devices to take them over, spread malware, and intercept communications — without pairing with the victims' devices. Which of the following describes this class of attack?

A. BlueBorne / BlueSmack (Bluetooth-based)
B. Evil twin
C. MAC address cloning
D. On-path via rogue DNS

**Q28.** Which of the following BEST distinguishes espionage from data exfiltration as a motivation?

A. Espionage involves spying on individuals, organizations, or nations to gather sensitive or classified information — often for national security, competitive business intelligence, or political advantage — whereas data exfiltration is the act of unauthorized data transfer itself
B. Espionage only occurs between nation-states; exfiltration only occurs within companies
C. Espionage uses only technical means; exfiltration uses only social engineering
D. There is no difference; they are synonyms on the exam

**Q29.** An attacker breaks into a wiring closet and taps the copper cabling to intercept network traffic, and also connects an unauthorized device by cloning an allowed MAC address and hopping between VLANs. Which threat vector does this describe?

A. Unsecured wired network
B. Unsecured wireless network
C. Removable device
D. Message-based

**Q30.** An analyst needs a solution that diverts attackers away from critical assets, wastes their time with fake DNS responses, raises alerts when they touch fake folders, and serves ever-changing content to confuse automated scraping bots. Which set of technologies matches ALL of these needs?

A. Bogus DNS entries, decoy directories, dynamic page generation
B. Honeytokens, honeypots, port triggering
C. Honeyfiles, honeynets, bogus DNS entries
D. Decoy directories, honeytokens, screen subnets

**Q1 — B.** Seven-month dwell time, stealth, stealing (not breaking) = textbook **APT / advanced persistent threat** performing data exfiltration. A is wrong (not opportunistic scanning), C and D both involve disruption — the scenario explicitly says none occurred.

**Q2 — C.** Threatening to release compromising material unless demands are met = **blackmail**. Classic trap: money is demanded, but the *mechanism* (threat of exposure) defines blackmail; sextortion/doxxing are its forms. "Financial gain" would be ransomware/stealing account funds without a threat of public exposure.

**Q3 — B.** Unapproved tech used for convenience without IT's knowledge = **shadow IT**. No malice → not framed as an insider *attack*, though shadow IT can create insider risk. A is a plausible trap — "insider threat" requires misuse/impact; the scenario describes the condition (shadow IT) itself.

**Q4 — B.** Deliberately mimicking another group's tooling to misdirect attribution = **false flag attack**. A is the general *operating style* (proxies give deniability); the specific deception technique described is a false flag.

**Q5 — B.** Vector = **how** (pathway/payload delivery); surface = **where** (sum of all entry points and vulnerabilities). This definitional pair appears constantly on the real exam.

**Q6 — B.** Leaving infected media where targets will find it = **baiting**. (Yes, "B" five times in a row on this key is a coincidence — on the real exam CompTIA balances answer positions; always read all options.)

**Q7 — B.** Honeypots do **not** prevent attacks — they **collect intelligence** on methods, motives, and TTPs. Any answer saying "block/prevent" is automatically wrong. D is wrong because an attack surface is not something you deliberately inflate as a control.

**Q8 — C.** Political cause, no financial demand, public credit-seeking = **hacktivist**. Techniques (defacement, leaks) don't define the actor — motivation does.

**Q9 — B.** A fake account/resource with **no legitimate use** whose mere access signals a breach = **honeytoken**. Honeyfile (A) is a decoy *file*; honeynet (C) is a decoy network.

**Q10 — C.** **North Korea** is the documented exception: sanctions and economic isolation push its state actors to rob banks and cryptocurrency exchanges to fund the regime.

**Q11 — B.** Uses a downloaded tool, can't write/modify it, motivated by notoriety = **script kiddie**. Trap: the "researcher" label doesn't make it ethical — there was no authorization.

**Q12 — C.** Malicious code embedded in image files/pixels = **image-based vector**. Stegano is the canonical SY0-701 example.

**Q13 — B.** Definition of **false flag**: disguised origin to mislead attribution. Trap A describes a跳板/compromised intermediary (different concept). C describes honeytokens; D describes evil twin.

**Q14 — D.** Structured, transnational, custom malware, purely profit-driven = **organized crime** (FIN7-style). Nation-state (B) would imply geopolitical, not profit, motives.

**Q15 — B.** The course's exact mitigation list: **zero trust, access controls, regular audits, awareness training**. A protects the perimeter (insiders are already inside); C treats a symptom; D alone is insufficient.

**Q16 — A.** Rogue AP impersonating a legitimate Wi-Fi network = **evil twin**. BlueBorne is Bluetooth; VLAN hopping is wired; baiting is USB drops.

**Q17 — B.** TTPs = the behavior/method fingerprint of a specific actor or group, used for detection and countermeasures. This acronym is everywhere in the objectives — memorize it.

**Q18 — A.** A whole decoy **network** of systems (servers/routers/switches) observing multi-stage, long-duration activity, logging success *and* failure = **honeynet**. A single honeypot is one decoy system; honeyfiles/honeytokens don't let attackers pivot between devices.

**Q19 — B.** Voice calls impersonating a trusted entity = **vishing** (voice-call vector). Trap: threatening arrest is just social pressure — still vishing, not a message-based phish.

**Q20 — B.** Honeypots/honeynets are a **double-edged sword**: attackers can fingerprint your production configuration from the decoys. A overstates — decoys don't block attacks. C is wrong — they belong in isolated/screened segments, NOT inline.

**Q21 — B.** Wronged employee harming the employer = **revenge** motivation; she has legitimate access = **internal** threat actor. Financial gain (A) would require profiting as the goal — her goal is harm.

**Q22 — A, C.** Surface reduction = **disable unused protocols** and **remove unnecessary software** (plus restrict access). B, D, and E all *expand* the surface with new avenues for attackers.

**Q23 — B.** Decoy **file** with fake data, watermarks, alert on access, possible attacker-network enumeration = **honeyfile**. A honeytoken is data/account-based, not a file lure (the names are annoyingly close — that's the point of the question).

**Q24 — B.** Unapproved cloud storage/plugins outside IT's visibility = **shadow IT** (a.k.a. stealth IT); risk = systems IT **cannot secure** → breaches, non-compliance, disruption. A describes actors, not the condition; C/D don't fit.

**Q25 — B.** Pen testers and bug-bounty hunters are motivated by **ethical reasons** — they mimic malicious actors *with authorization* to harden defenses. Don't let "they get paid bounties" trick you into "financial gain."

**Q26 — B.** **Stuxnet**: attributed to US/Israel; multiple zero-days; crossed an **air gap via infected USB**; physically destroyed centrifuges. The canonical nation-state/sabotage example.

**Q27 — A.** **BlueBorne** (and BlueSmack) = Bluetooth protocol vulnerabilities enabling device takeover, malware spread, and interception. Evil twin is Wi-Fi; MAC cloning/VLAN hopping are wired-network tricks.

**Q28 — A.** Espionage is a *motivation* (spying for strategic advantage); exfiltration is an *act/technique*. Exfiltrated data can serve espionage. B–D are false absolutes — classic CompTIA "extreme wording" distractors.

**Q29 — A.** Tapping cables, MAC cloning, VLAN hopping = attacks against an **unsecured wired network**. Wireless (B) would involve evil twins/wardriving.

**Q30 — A.** Bogus DNS entries (fake DNS responses) + decoy directories (fake folders that alert) + dynamic page generation (confuse crawlers/bots) — all are **disruption** technologies. The other mixes are deception tech that don't cover dynamic pages.
